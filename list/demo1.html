HomePage is the main page of a website that serves as an entry point for visitors. It typically provides an overview of the website's content and navigation options.
  1. HTML

    2. HTML is the standard markup language for creating web pages and web applications. With Cascading Style Sheets (CSS) and JavaScript, it forms a triad of cornerstone technologies for the World Wide Web. HTML is written in the form of HTML elements consisting of tags enclosed in angle brackets (like ), within which web content can be placed. The structural layout of a web page is defined by HTML, while CSS is used to control the presentation, formatting, and layout, and JavaScript is used to control the behavior of different elements.

  2. CSS

    3. CSS is a style sheet language used for describing the presentation of a document written in HTML or XML. CSS describes how elements should be rendered on screen, on paper, in speech, or on other media.

  3. JAVASCRIPT

    4. JavaScript is a programming language that enables interactive web pages. It is an essential part of web applications and is used to create dynamic content, handle events, and manipulate the Document Object Model (DOM).
